Every paper decision is a mechanical check. The engine evaluates both sides (UP and DOWN) of the live window for each asset × horizon once per second. A side can trade only if it passes all six rules and then all portfolio gates. The grid's Reason column shows the first thing that blocks the better side; click a grid row on the terminal for the full checklist with numbers.

OPERATOR CONTROLS (TERMINAL → CONTROLS PANEL)

Controls are paper only. Every change is validated against hard bounds and written as a new version of data/runtime/controls.json. The engine and execution workers apply it within about a second and report the version they applied; the panel shows ✓ when both have it. Every change is logged in Events with its old → new values and an optional note. Writes need the dashboard token in the X-Dashboard-Token header, so a URL alone cannot change anything. Unknown keys, including anything about mode, keys or live trading, are rejected.

ControlBoundsConfig defaultEffective now
  • Flatten & pause: type FLATTEN. Every open paper position is closed at the current bid minus the taker fee and recorded as settled ("flattened at bid … by operator"), and new entries are paused. A position with no bid is left to settle at expiry.
  • Reset to config defaults puts every control back to the values in config.yaml / strategies/default.yaml.
  • HALT reset is not a control. It stays on the CLI (scripts/reset_halt.sh --yes on the droplet) and should only be run after the HALT's cause is understood.
